    🔑 Ключові відмінності гібридної версії

    Математична точність

    Українська версія включає точні формули:

    z = |r| / σ_total
d² = rᵀ S⁻¹ r

    Конкретні пороги

    • ACCEPT: z ≤ φ (або d² ≤ q1)
    • UNKNOWN: φ < z ≤ π (або q1 < d² ≤ q2)
    • REJECT: z > π (або d² > q2)

    Вимірювані KPI

    Pilot: - unsafe actions = 0 (обов'язково) - TPR ≥ 95%, FPR ≤ 5% - median recovery ≤ 10 sec

    Production: - Інциденти: 5-10 → < 1 (на 100 год) - Interventions: 2-5 → < 0.5 (на годину) - Mission success: 60-80% → > 95%
