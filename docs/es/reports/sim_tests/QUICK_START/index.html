    ⚡ Quick Start Guide — Chi² Stress Test

    🎯 Швидкий запуск

    1️⃣ Базовий тест (100k cycles, DEFAULT mode)

    python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000

    2️⃣ Усі режими (рекомендовано)

    # DEFAULT
python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 --mode default --dof 6 --seed 42

# CRUISE (найкращий результат)
python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 --mode cruise --dof 6 --seed 42

# PRECISION (жорсткий)
python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 --mode precision --dof 6 --seed 42

    3️⃣ Кастомні параметри

    python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 `
  --mode default `
  --dof 6 `
  --seed 42 `
  --spoof-prob 0.02 `
  --q1-mult 0.9 `
  --q2-mult 1.3 `
  --unknown-weight 0.4

    📊 Параметри

    Параметр Опис Default Опції
    cycles Кількість циклів 10000 будь-яке число
    --dof Degrees of freedom (ν) 6 2-9 (precomputed)
    --mode Режим роботи default default, cruise, precision
    --seed Random seed (для reproducibility) None будь-яке число
    --spoof-prob Ймовірність spoof injection залежить від mode 0.0–1.0
    --q1-mult Множник для q₁ (ACCEPT threshold) залежить від mode 0.5–2.0
    --q2-mult Множник для q₂ (REJECT threshold) залежить від mode 0.5–2.0
    --unknown-weight Вага UNKNOWN у health score залежить від mode 0.0–1.0
    --temp-alpha Температурний коефіцієнт 1.0 0.1–5.0
    --t-min Мінімальна температура 0.0 0.0–1.0
    --t-max Максимальна температура 0.5 0.0–1.0

    🏆 Рекомендовані налаштування

    Для продакшн (після калібрації):

    python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 `
  --mode cruise `
  --dof 6 `
  --seed 42 `
  --q2-mult 1.5 `
  --unknown-weight 0.4

    Для дебагу (швидко):

    python docs\reports\sim_tests\src\mass_stress_test_chi2.py 1000 `
  --mode default `
  --dof 6

    Для стрес-тесту (максимум):

    python docs\reports\sim_tests\src\mass_stress_test_chi2.py 1000000 `
  --mode precision `
  --dof 9 `
  --spoof-prob 0.05

    📁 Де знайти результати

    Після виконання тесту:

    1. Console output — відображається в реальному часі

    2. Створити звіт вручну: powershell python docs\reports\sim_tests\src\mass_stress_test_chi2.py 100000 --mode cruise > logs\my_test_$(Get-Date -Format 'yyyy-MM-dd').log

    3. Переглянути існуючі звіти:

    4. logs/chi2_stress_100k_2026-01-13.md
    5. FINAL_REPORT_UA.md

    🔍 Інтерпретація результатів

    Health Score

    • > 90% → STABLE ✅
    • 70–90% → DEGRADED ⚠️
    • < 70% → UNSTABLE ❌

    Weighted Health Formula:

    Health = (ACCEPT + unknown_weight × UNKNOWN) / total_cycles × 100%

    Приклад:

    ACCEPT: 26,463 (26.46%)
UNKNOWN: 38,919 (38.92%)
unknown_weight: 0.35

Health = (26,463 + 0.35 × 38,919) / 100,000 × 100%
       = (26,463 + 13,622) / 100,000 × 100%
       = 40.08% → UNSTABLE

    ⚠️ Troubleshooting

    Помилка: "UnicodeEncodeError"

    Рішення: Скрипт вже виправлений (використовує ASCII замість χ²/φ/π)

    Дуже високий REJECT (>50%)

    Причина: Модель шуму занадто агресивна
    Рішення: Зменшити діапазон noise_factor у скрипті або збільшити q2-mult

    Нульовий ACCEPT (<10%)

    Причина: q1-mult занадто малий
    Рішення: Збільшити до 1.0 або вище

    Повільна симуляція

    Причина: Багато циклів
    Рішення: Зменшити кількість циклів для debug (1k–10k)
