    🧪 Simulation Report: 110kV Wire Landing & Physics

    Date: 2026-01-14 Script: sim_physics_wire_landing.py Status: ✅ Validated (Physics + Safety Constraints)

    1. Physics Model Updates

    A. Current-Driven Induction

    Unlike previous voltage-based approximations, this simulation uses Amperage (I_rms) to drive magnetic flux, which is the physically correct method for inductive harvesting. - Formula: $B(r) \approx \frac{\mu_0 I}{2\pi r}$ - Current Load: 450A RMS - Resulting Field: ~100-500 $\mu T$ near wire.

    B. Split-Core Efficiency (Gap Logic)

    We modeled the impact of the magnetic core gap on power transfer. Power drops significantly if the core is not fully closed. - Open Gap: Power $\approx$ 0W - Closed Gap (0mm): Power $\approx$ 157.5W - Latching Mechanics: A simulated "mechanical funnel" assists the final 15cm capture.

    2. Sensor Performance & Noise

    A. Magnetometer Failure (EMI)

    The simulation confirms that within 2.0m of the 110kV line, the magnetometer becomes unreliable due to EMI saturation ($>500\mu T$). - Action: System automatically switches to PURE VISUAL NAV mode when $<2m$. - Status: MAG_JAMMED flag correctly triggered.

    B. Visual Servo Precision

    • Approach: 1px noise = ~10cm error.
    • Terminal: 1px noise = ~1mm error.
    • Result: Successful alignment within ±10mm tolerance using visual feedback alone in terminal phase.
