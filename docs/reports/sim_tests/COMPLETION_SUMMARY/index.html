    ⚠️ Критичні висновки:

    1. Всі режими показали UNSTABLE

    Причини: - Модель шуму noise_factor ∈ [0.1..5.0] занадто агресивна - Квантилі q₁/q₂ розраховані для ідеальної статистики, не реального світу - σ_meas та σ_pred не відповідають реальним сенсорам sbsQ

    2. REJECT переважає ACCEPT (2:1 ratio)

    Рекомендації: - Збільшити q₂ на 30–50% (не тільки 20%) - Зменшити діапазон noise_factor до [0.1..3.0] - Калібрувати σ під реальні дані

    3. Spoof detection працює, але занадто чутливий

    • PRECISION виявив 1,943 спуфів (2% injection rate)
    • Але також 43% REJECT → багато false positives
    • CRUISE — кращий баланс (952 спуфів, 34.6% REJECT)
