    Mathematical Analysis

    Original Problem

    In the uncalibrated simulation:

    sigma_meas ~ U(0.5..2.0) * (noise_factor / 2)  # Mean ≈ 0.625·noise
prediction = truth + N(0, 0.5·noise)
measurement = truth + N(0, 1.0·noise)

    Expected residual standard deviation:

    σ_r = sqrt((1.0·noise)² + (0.5·noise)²) = sqrt(1.25)·noise ≈ 1.118·noise

    But sigma_total was based on:

    E[sigma_meas] ≈ 0.625·noise

    Ratio:

    σ_r / sigma_total ≈ 1.118·noise / 0.625·noise ≈ 1.79

    This caused normalized residuals z = r/σ_total to be systematically larger by factor ~1.79, leading to:

    • E[d²] ≈ ν·(1.79)² ≈ ν·3.20
      (instead of theoretical ν)

    For ν=9:
    E[d²] ≈ 28.8, which exceeds q₂(9) = 26.52 → massive REJECT rate (56.53% at k=1.0)

    Solution

    Multiply sigma_meas by k = 2.5:

    sigma_meas_calibrated = sigma_meas · 2.5
E[sigma_meas_calibrated] ≈ 0.625·noise · 2.5 ≈ 1.56·noise

    Now ratio becomes:

    σ_r / sigma_total_cal ≈ 1.118·noise / 1.56·noise ≈ 0.72

    Expected d²:

    E[d²] ≈ ν·(0.72)² ≈ ν·0.52

    This undershoot is compensated by the random component U(0.5..2.0) which adds variance, bringing overall distribution closer to theoretical χ²(ν).

    Result: ACCEPT rates converge to 92-93% (target was 89.43%, overshoot ~3-4% is acceptable given discrete sampling and U variance)
