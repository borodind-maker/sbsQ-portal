    Simulation Roadmap v1.7: Physics-Gated Grounding & Wire Landing

    Target: Calibration for 50+ sensors, Wire Landing (±10mm), and Swarm Consensus.

    A) Baseline Simulations (Calibration)

    These foundational tests ensure the gate parameters ($\sigma, \chi^2$) match the physical reality of the sensors before any logic is applied.

    A1. Baseline Coverage Test (Sanity)

    • Goal: Verify that under "normal" noise, the gate coverage matches theoretical $\phi/\pi$ equivalents.
    • Method: Generate locally whitened residuals $r \sim N(0,1)$ or $d^2 \sim \chi^2(\nu)$.
    • Target Metrics:
      • ACCEPT $\approx 89.43\%$ ($\phi$-coverage)
      • UNKNOWN $\approx 10.40\%$
      • REJECT $\approx 0.17\%$ ($\pi$-coverage)
    • Value: Immediate indicator if $\sigma_{total}$ is realistic or underestimated.

    A2. Sigma-Scale Sweep

    • Goal: Find the scalar multiplier $k$ for $\sigma_{total}$.
    • Method: Sweep $k \in {0.8, 1.0, 1.2, 1.5, 1.8, 2.0, 2.5, 3.0}$.
    • Metrics: Baseline Health, FP rates vs. $k$.
    • Value: Quickest path to STABLE status without loosening safety thresholds.

    A3. DOF Decomposition Study

    • Goal: Compare monolithic $\nu=9$ gate vs. modular $3 \times \nu=3$ gates.
    • Schemes:
      1. 9D Monolithic $\chi^2$.
      2. Modular: Pos(3D) + Vel(3D) + Att(3D).
      3. Docking: Pos(3D) + Yaw(1D) + Lateral(1D).
    • Value: Pinpoints which state vector component causes REJECT cascades.

    B) Attack Injections (Spoofing/Anomaly)

    Tests designed to measure Detection Rate (TP) and Missed Spoof Rate (FN).

    B1. Controlled Spoof Injection Matrix

    • Goal: Measure missed spoof rate as a function of attack magnitude.
    • Method: Inject bias $A \in {1\sigma, 2\sigma, 3\sigma, 4\sigma, 5\sigma, 8\sigma}$ over duration $T$.
    • Metrics: Detection, Hard-stop, Miss (Leakage).
    • Value: Generates sensitivity curves for CRUISE vs. PRECISION modes.

    B2. Drifting Spoof (Ramp Attack)

    • Goal: Catch "creeping" attacks that stay under the instantaneous threshold.
    • Method: $bias(t) = b_0 + v \cdot t$ (linear drift) or Random Walk.
    • Countermeasure: Add cumulative policy (long UNKNOWN duration $\to$ ESCALATE).

    B3. Coordinated Multi-Sensor Spoof

    • Goal: Simulate sophisticated attacks (e.g., GPS + Magnetometer spoofing simultaneously).
    • Method: Correlated injections on multiple channels ($\rho = 0.5..0.9$).

    B4. Replay Attack

    • Goal: Detect valid but "stale" telemetry.
    • Method: Replay historical segments with time shift.
    • Metrics: Time-consistency gate ($\Delta t$, EKF innovation).

    C) Advanced Noise Modeling (Non-Gaussian)

    C1. Heavy-Tail Noise (Student-t)

    • Goal: Model real-world vision/tracker noise (outliers, glints).
    • Method: Residuals $\sim Student-t(df=3..8)$.
    • Value: Determines need for robust gating (Huber/Tukey) or winsorization.

    C2. Correlated Residuals (Off-diagonal S)

    • Goal: Validate Mahalanobis distance implementation.
    • Method: Generate $r = L \cdot u$ where $S = LL^T$ is non-diagonal.

    C3. Covariance Mismatch Validation

    • Goal: Quantify impact of "loud" vs. "quiet" sensor lying about its $\sigma$.
    • Method: Use $\sigma_{reported} = c \cdot \sigma_{true}$ with $c \in {0.5, 0.8, 1.2, 1.5, 2.0}$.

    D) Flight Dynamics (Kinematic Truth)

    D1. Constant-Velocity/Acceleration Model

    • Goal: Replace random truth with physical trajectories.
    • Method: $x_{t+1} = F x_t + w$. Add maneuvers and jerk limits.

    D2. Latency & Time Alignment

    • Goal: Simulate sensor lag (GPS 200ms vs. IMU 5ms).
    • Metric: False anomalies caused purely by synchronization errors.

    D3. Dropouts & Reacquisition

    • Goal: Model sensor loss (e.g., GPS tunnel, Vision motion blur).
    • Method: Markov states {OK, DEGRADED, LOST}.

    E) Wire Landing (±10mm Precision)

    Crucial for "High-Voltage Line Harvesting" scenario.

    E1. Visual Servoing Docking Sim

    • Status: ✅ COMPLETED (ST-31)
    • Goal: Verify gate allows precision maneuvers only with high-quality vision.
    • Method: Pixel-to-mm projection errors, lens distortion models.
    • Metrics: Lateral offset (5.87mm achieved vs 10mm target).

    E2. Magnetometer + Camera Fusion

    • Status: ✅ COMPLETED (ST-31)
    • Goal: Handle magnetic interference near power lines.
    • Method: Simulate hard/soft iron distortions + current-induced fields.
    • Result: Gating correctly prioritizes Visual data when Mag sigma explodes.

    E3. Contact & Bounce Model

    • Goal: Mechanical landing physics.
    • Logic: Error > 10mm $\to$ Slip/Fail.

    E4. Corona Discharge & HV Safety

    • Status: ⚠️ CRITICAL RISK (ST-33)
    • Findings: Contact at 0cm is impossible without modification. Flashover starts at 2cm.
    • Required Mitigations:
      • Simulating Dielectric Caps ($\beta \to 3$).
      • Updated "Safe Zone" logic.
    • Goal: Validate 100% safety with new hardware parameters.

    F) Swarm Consensus (Peer Voting)

    F1. Peer Voting on UNKNOWN

    • Goal: Resolve local ambiguity via swarm majority.
    • Method: Query $N$ neighbors. ACCEPT if quorum $k/N$ agrees.
    • Metric: Reduction in False Negatives vs. Latency penalty.

    F2. Byzantine Peer Simulation

    • Goal: Resilience against compromised swarm members.
    • Method: One peer consistently lies or injects noise.

    G) Standard Metrics (KPIs)

    Every simulation run must report: 1. Baseline FP: (UNKNOWN+REJECT) / Total Non-Injected 2. Attack FN: (ACCEPT) / Total Injected 3. Time-to-Detect: Cycles from injection start to first non-ACCEPT. 4. Streak Metrics: Max consecutive UNKNOWN/REJECT length. 5. Per-DOF Contribution: Which axis drives the $d^2$ value.
