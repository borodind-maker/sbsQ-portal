    Document Type: Pricing Strategy

    F1. SDK Licensing Tiers

    Base Package

    Target Customer: Small fleets, R&D teams, proof-of-concept deployments

    Included: - ✅ Core gate engine (z-score, χ² verification) - ✅ Basic logging & audit trail - ✅ Standard sensor profiles (GNSS, IMU, vision) - ✅ Community support (forum, documentation) - ✅ Up to 5 devices

    Not Included: - ❌ Advanced calibration toolkit - ❌ Mode-specific thresholds - ❌ Replay/verification tools - ❌ SLA/dedicated support

    Pricing: - Annual License: $15,000/year - Per-Device: $3,000/device/year (volume discount at 5+)

    Pro Package

    Target Customer: Medium deployments, commercial operators, industrial integrators

    Included: - ✅ Everything in Base - ✅ χ² lookup tables (precomputed for ν ≤ 9) - ✅ Mode thresholds (cruise/approach/precision) - ✅ Replay toolkit (incident reconstruction) - ✅ Advanced audit artifacts - ✅ Calibration toolkit v1 (offline, batch) - ✅ Integration adapters (ROS, PX4, ArduPilot) - ✅ Email support (48-hour response) - ✅ Up to 25 devices

    Pricing: - Annual License: $75,000/year (flat rate, up to 25 devices) - Per-Device (26+): $2,500/device/year - Per-Fleet: $60,000/year (unlimited devices, single deployment site)

    Enterprise Package

    Target Customer: Large-scale deployments, critical infrastructure, defense

    Included: - ✅ Everything in Pro - ✅ Dedicated SLA (24-hour response, 99.5% uptime) - ✅ Custom integration support - ✅ On-site training (2 sessions/year) - ✅ Safety Case generation toolkit - ✅ Compliance artifacts (DO-178C, ISO 26262 templates) - ✅ Priority feature requests - ✅ Multi-site deployment support - ✅ Unlimited devices

    Pricing: - Annual License: $250,000–$500,000/year (based on scope) - Per-Site: $200,000/year (unlimited devices per site) - Custom: Contact for multi-year, multi-site agreements

    Add-Ons: - Dedicated support engineer: +$150,000/year - Custom feature development: Quote-based - Certification support: +$50,000–$200,000 (one-time)

    Defense/Government Package

    Target Customer: Military, national security, classified deployments

    Included: - ✅ Everything in Enterprise - ✅ Air-gapped deployment support - ✅ Hardened security features - ✅ Export control compliance (ITAR/EAR) - ✅ Classified environment integration - ✅ On-premise deployment (no cloud dependency) - ✅ Source code escrow (optional)

    Pricing: - Custom Quote (typically $500K–$2M/year) - Contact for government contracting terms

    F2. Pilot Program Pricing

    Proof-of-Concept Pilot (4 weeks)

    Scope: - 1 flagship scenario - 100 test runs - Basic metrics (safety, FP/FN, recovery time) - Pilot report

    Pricing: $25,000–$40,000 (fixed fee)

    Option: 50% credit toward first-year license if customer proceeds

    Standard Pilot (6–8 weeks)

    Scope: - 3 scenarios from test matrix - 500 test runs - Full metrics suite - Sensor profiling - Mode threshold calibration - Pilot report + deliverables

    Pricing: $50,000–$75,000 (fixed fee)

    Option: 30% credit toward first-year license

    Comprehensive Pilot (8–12 weeks)

    Scope: - 7+ scenarios (full test matrix) - 1,000+ test runs - Real-world deployment validation - Operator training - Safety Case template - Replay package

    Pricing: $100,000–$150,000 (fixed fee)

    Option: 20% credit toward first-year license + priority onboarding

    F8. ROI Calculator (Customer-Facing)

    Cost of Incidents (Without sbsQ)

    Assumptions: - Fleet size: 20 UAVs - Incident rate: 5% per mission - Missions per year: 1,000 - Cost per incident: $50,000 (vehicle damage, downtime, investigation)

    Annual incident cost: 1,000 × 0.05 × $50,000 = $2,500,000

    Cost Reduction (With sbsQ)

    Assumptions: - sbsQ reduces incident rate to 0.5% (10× improvement) - Annual license: $75,000 (Pro package)

    New annual incident cost: 1,000 × 0.005 × $50,000 = $250,000

    Savings: $2,500,000 - $250,000 - $75,000 = $2,175,000/year

    ROI: ($2,175,000 / $75,000) × 100 = 2,900%

    Payback period: < 2 weeks

    F10. Frequently Asked Questions

    Q: Can we start with Base and upgrade later?

    A: Yes. Upgrades are prorated based on time remaining in license term.

    Q: Do you offer month-to-month licensing?

    A: Not currently. Minimum term is 1 year. Pilots are available for shorter evaluation.

    Q: What happens if we exceed device limits?

    A: Automatic upgrade to next tier or per-device billing (whichever is more cost-effective).

    Q: Is there a free trial?

    A: We offer a 4-week pilot program (paid) with license credit. No free trials, but we guarantee measurable results or refund.

    Q: Can we negotiate custom terms?

    A: Yes, for Enterprise and Defense customers. Contact sales.
