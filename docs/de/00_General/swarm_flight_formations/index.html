    🌐 Фігури Польоту Рою SmartBees

    Версія: 2.0
    Дата: 2026-01-25
    Автор: sbsQ Development Team

    📋 Огляд

    SmartBees підтримує 6 типів геометричних формацій для різних тактичних завдань. Кожна формація базується на природних математичних константах для оптимального розподілу дронів у просторі.

    🌟 1. FIBONACCI_SPHERE (Сфера Фібоначчі)

    Математична основа

    • Константа: Золотий перетін (PHI = 1.618033988...)
    • Кут: GOLDEN_ANGLE_RAD ≈ 2.3999 rad (137.5°)

    Візуалізація

          ●
   ●  ●  ●
 ●  ●  ●  ●
●  ●  ●  ●  ●
 ●  ●  ●  ●
   ●  ●  ●
      ●

    Характеристики

    • Виміри: 3D (сферичний розподіл)
    • Ефективність покриття: 95% (сфера)
    • Складність: O(1) на позицію
    • Унікальність: Рівномірний розподіл без кластерування

    Використання

    • 🔭 Спостереження/розвідка - рівномірний огляд у всіх напрямках
    • 📡 Моніторинг об'єкта на 360°
    • 🎯 Мінімізація сліпих зон
    • 🛡️ Захист периметра зі всіх боків

    Приклад коду

    from smartbees.core.nature_math import QuantumNatureProtocol

# 5 дронів на сфері радіусом 15м
for i in range(5):
    x, y, z = QuantumNatureProtocol.get_swarm_position(i, 5, radius=15.0)
    print(f"Drone {i}: ({x:.1f}, {y:.1f}, {z:.1f})")

    Сценарії

    • Патрулювання критичної інфраструктури
    • Охорона VIP-персон
    • Розвідка невідомої території

    🛡️ 2. SILVER_OCTAGON (Срібний Восьмикутник)

    Математична основа

    • Константа: Срібний перетін (SILVER_RATIO = 1 + √2 ≈ 2.414213562...)
    • Кут кроку: 45° (π/4) × SILVER_RATIO

    Візуалізація

        ●₈
  ●₇  ●₁
●₆  C  ●₂   ← 8 позицій
  ●₅  ●₃       на кільці
    ●₄

Багато кілець:
  Ring 2:  ●────●
          /│    │\
Ring 1: ●  C───C  ●
          \│    │/
           ●────●

    Характеристики

    • Виміри: 2D + висотна диференціація
    • Ефективність покриття: 85% (кільця)
    • Складність: O(1) на позицію
    • Унікальність: Масштабування кілець за срібним перетином

    Використання

    • 🛡️ Оборонні периметри - захист об'єкта
    • 🚧 Створення багатошарової "стіни"
    • ⚡ Швидка перебудова кілець
    • 🎯 Контроль доступу до зони

    Приклад коду

    # 16 дронів (2 кільця по 8)
for i in range(16):
    x, y, z = get_silver_octagon_position(i, total=16, radius=20.0)
    ring = i // 8
    print(f"Drone {i} (Ring {ring}): ({x:.1f}, {y:.1f}, {z:.1f})")

    Сценарії

    • Захист воєнної бази
    • Периметр навколо небезпечної зони
    • Контроль кордону території

    🌀 3. PADOVAN_SPIRAL (Спіраль Падована)

    Математична основа

    • Константа: Пластичне число (PLASTIC_NUMBER ≈ 1.324717957...)
    • Послідовність: P(n) = P(n-2) + P(n-3)

    Візуалізація

            ●₅
      ↗
    ●₄
  ↗
●₃      ← Спіраль
↑         розширюється
●₂        природно
↑
●₁ (start)

3D вид:
    z
    ↑   ●₅
    │ ↗
    ●₄
  ↗
●₃─────→ y
│
●₂
│
●₁
│
x

    Характеристики

    • Виміри: 3D (спіральне розширення)
    • Ефективність покриття: 80% (розширення)
    • Складність: O(1) на позицію
    • Унікальність: Природне зростання радіусу

    Використання

    • 🔍 Пошукові операції - систематичне сканування
    • 📈 Природне розширення зони пошуку
    • 🎯 Знаходження пропалих осіб/об'єктів
    • 🌊 Розширення від епіцентру

    Приклад коду

    # 10 дронів у пошуковій спіралі
for i in range(10):
    x, y, z = get_padovan_spiral_position(i, total=10, radius=5.0)
    distance = math.sqrt(x**2 + y**2)
    print(f"Drone {i}: r={distance:.1f}m, z={z:.1f}m")

    Сценарії

    • Пошук загублених людей у лісі
    • Розширення зони після виявлення об'єкта
    • Систематичне сканування невідомої території

    🐝 4. HEXAGONAL_GRID (Гексагональна Сітка)

    Математична основа

    • Константа: SQRT3 ≈ 1.732050808...
    • Ефективність: 90.69% (найкраща для площини)

    Візуалізація

      ● ● ●
 ● ● ● ●    ← Стільники
● ● ● ● ●     (honeycomb)
 ● ● ● ●
  ● ● ●

Геометрія:
   ⬡
  ⬡⬡    spacing = radius / √3
 ⬡⬡⬡
  ⬡⬡
   ⬡

    Характеристики

    • Виміри: 2D (планарне покриття)
    • Ефективність покриття: 90.69% (максимальна!)
    • Складність: O(1) на позицію
    • Унікальність: Nature's perfect packing

    Використання

    • 🌾 Сільське господарство - максимальне покриття полів
    • 📸 Аерофотозйомка великих площ
    • 🗺️ Картографування території
    • 🎯 Мінімальне перекриття зон

    Приклад коду

    # 30 дронів для поля 500×500м
area = 500 * 500  # m²
drone_coverage = 50 * 50  # m² per drone
spacing = 50 / SQRT3

for i in range(30):
    x, y, z = get_hexagonal_grid_position(i, spacing=spacing)
    print(f"Drone {i}: ({x:.1f}, {y:.1f})")

    Сценарії

    • Обприскування сільгосп полів
    • Сканування великих площ для карт
    • Моніторинг лісових насаджень

    📦 5. CUBIC_LATTICE (Кубічна Гратка)

    Математична основа

    • Константа: CUBE_ROOT_2 ≈ 1.259921050...
    • Структура: 3D куб з рівномірними інтервалами

    Візуалізація

        ●───●───●
   /│  /│  /│
  ● ●─● ●─● │   ← 3×3×3 = 27 дронів
  │ ●─│─●─│─●
  │/  │/  │/
  ●───●───●

Вид збоку:
z₂  ●───●───●
    │   │   │
z₁  ●───●───●
    │   │   │
z₀  ●───●───●
    x₀  x₁  x₂

    Характеристики

    • Виміри: 3D (кубічна структура)
    • Ефективність покриття: 78% (куб)
    • Складність: O(1) на позицію
    • Унікальність: Рівномірний 3D розподіл

    Використання

    • 📦 3D сканування будівель, складів
    • 🏗️ Інспекція високих конструкцій
    • 🌲 Моніторинг лісу (різні висоти)
    • 🏭 Інспекція заводів/фабрик

    Приклад коду

    # 27 дронів (3×3×3) для 10-поверхової будівлі
cells_per_side = 3
for i in range(27):
    x, y, z = get_cubic_lattice_position(i, cells_per_side=3, radius=15.0)
    floor = int(z / 3) + 1
    print(f"Drone {i}: Floor {floor}, ({x:.1f}, {y:.1f}, {z:.1f})")

    Сценарії

    • Інспекція багатоповерхівок
    • 3D моделювання будівель
    • Інвентаризація складів

    📐 6. GOLDEN_RECTANGLE (Золотий Прямокутник)

    Математична основа

    • Константа: PHI = 1.618... (співвідношення сторін)
    • Пропорція: width : height = 1.618 : 1

    Візуалізація

    ●─────────────────────────●
│  ●   ●   ●   ●   ●   ●  │
│                         │  ← Співвідношення
│  ●   ●   ●   ●   ●   ●  │    1.618:1
│                         │
│  ●   ●   ●   ●   ●   ●  │
●─────────────────────────●

Вид зверху:
←──── 1.618 × L ────→
↑  ● ● ● ● ● ●
L  ● ● ● ● ● ●
↓  ● ● ● ● ● ●

    Характеристики

    • Виміри: 2D (прямокутна зона)
    • Ефективність покриття: 82% (прямокутник)
    • Складність: O(1) на позицію
    • Унікальність: Естетично оптимальні пропорції

    Використання

    • 🛣️ Моніторинг доріг та лінійної інфраструктури
    • 🌉 Інспекція мостів, трубопроводів
    • 📏 Прямокутні зони з оптимальним співвідношенням
    • 🏞️ Панорамна зйомка ландшафтів

    Приклад коду

    # 15 дронів для моніторингу 2км автомагістралі
width = 2000  # 2km
height = width / PHI  # ~1.236 km
for i in range(15):
    x, y, z = get_golden_rectangle_position(i, total=15, width=width, height=height)
    km_mark = x / 1000
    print(f"Drone {i}: km {km_mark:.2f}, lane offset {y:.1f}m")

    Сценарії

    • Патрулювання автомагістралей
    • Інспекція залізничних колій
    • Моніторинг кордонів/огорож

    🔧 Технічна реалізація

    API Enum

    from enum import Enum

class SwarmFormationType(Enum):
    FIBONACCI_SPHERE = "fibonacci_sphere"
    SILVER_OCTAGON = "silver_octagon"
    PADOVAN_SPIRAL = "padovan_spiral"
    HEXAGONAL_GRID = "hexagonal_grid"
    CUBIC_LATTICE = "cubic_lattice"
    GOLDEN_RECTANGLE = "golden_rectangle"

    Універсальна функція

    def get_formation_position(
    formation_type: SwarmFormationType,
    node_index: int,
    total_nodes: int,
    radius: float = 10.0,
    **kwargs
) -> Tuple[float, float, float]:
    """
    Розраховує позицію дрона в формації.

        total_nodes: Загальна кількість дронів
        radius: Базовий радіус формації
        **kwargs: Додаткові параметри (spacing, height_step, etc.)

    Returns:
        (x, y, z): Координати в метрах
    """

    📈 Ефективність покриття

    Математичне обґрунтування

    Hexagonal Grid (90.69%): - Теорема про щільну упаковку кіл - π/(2√3) ≈ 0.9069 - Найкраща для 2D площин

    Fibonacci Sphere (95%): - Рівномірний розподіл точок на сфері - Мінімізація Voronoi variance - Найкраща для 3D огляду

    Cubic Lattice (78%): - Простота структури vs щільність - Trade-off: легкість обчислення

    🚀 Performance

    Всі формації мають O(1) складність на позицію: - ⚡ < 0.01ms per calculation - 💾 Minimal memory (3 floats per drone) - 🔄 Real-time recalculation possible

    📚 Посилання

    1. Fibonacci Sphere: Vogel, H. (1979). "A better way to construct the sunflower head"
    2. Silver Ratio: de Spinadel, V. (1999). "The Metallic Means Family"
    3. Padovan Spiral: Padovan, R. (1994). "Dom Hans van der Laan: Modern Primitive"
    4. Hexagonal Packing: Hales, T. (2001). "The Honeycomb Conjecture"
    5. Cubic Lattice: Minkowski, H. (1907). "Geometrie der Zahlen"
    6. Golden Rectangle: Livio, M. (2002). "The Golden Ratio"
