    🏗️ Architecture Overview: The Logical Flow

    Philosophy: "High-Resilience" Autonomous Design

    SmartBees Quantum (sbsQ) is designed as a mission-critical autonomous framework. Its core principles ensure reliable performance in complex, unpredictable environments:

    1. Resilience First: The system is built to maintain operational integrity even during partial failure or high-latency scenarios.
    2. Brain-Body Separation: Cognitive functions (Strategic Planning/AI) are separate from execution (Navigation/Sensors). This ensures that heavy processing tasks never block real-time safety reflexes.
    3. Ternary State Logic: Utilizing (-1, 0, +1) states allows the system to handle uncertainty, neutral zones, and complex decision-making more effectively than standard binary logic.

    The 6-Layer Operational Flow

    The system follows a logical data flow, from configuration to communication:

    1. ⚙️ Configuration (config/): The foundation. Defines behavioral constants, safety envelopes, and operational limits.
    2. ⚛️ Core (smartbees/core/): The engine. Manages threading, event loops, and basic system stability.
    3. 🧠 Brain (smartbees/brain/): The intelligence. Handles quantum decision-making, self-reflection, and long-term planning.
    4. 🚀 Application (smartbees/app/): The execution. Mission scenarios, autopilot, and real-time navigation.
    5. 📡 Sensors (smartbees/sensors/): The perception. Interfaces with 50+ hardware units to build world awareness.
    6. 📶 Communication (smartbees/comm/): The social layer. Connects nodes into a unified Swarm Network.
