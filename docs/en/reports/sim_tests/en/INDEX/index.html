    📖 Appendix: Glossary & Formulas

    • REB (Reflex Breaker): Algorithm for breaking resonance loops in the control chain.
    • Antigravity Kick: Forced reset of the control vector to neutral state upon deviation > THRESHOLD.
    • Safety Kick: One-time state machine correction to exit a loop state (L-loop).
    • SNR (Signal-to-Noise Ratio): 10 * log10(P_signal / P_noise).
    • J/S Ratio (Jamming-to-Signal): 10 * log10(P_jam / P_signal).
    • PHI Definition: GHS-Harmonic Threshold (0.618...), used as a dynamic threshold.

    Any unauthorized modification of artifacts is detectable via SHA-256 hash mismatch.
