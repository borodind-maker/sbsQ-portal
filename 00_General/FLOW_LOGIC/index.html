    🌊 Flow Logic: The sbsQ Operational Stack

    The SmartBees Quantum (sbsQ) system operates on a 6-layer sequential and reactive logic stack. This "Flow Logic" ensures that data moves from raw configuration to synchronized action with maximum efficiency and safety.

    1. ⚙️ Layer: Configuration (The DNA)

    Directory: /config, /smartbees/config Role: Initialization and Constraints.

    This is the static foundation of the system. - Safety Envelopes: Hard limits for speed, altitude, and current. - Hardware Profiles: Calibration data for specific sensors and actuators. - Constants: Fundamental values (Schumann Resonance, Golden Ratio) used for synchronization. - Contracts: Data structures that define how different modules must communicate.

    2. ⚛️ Layer: Core (The Engine)

    Directory: /smartbees/core Role: Resource Management and Stability.

    The Core layer is responsible for keeping the "body" alive. - Event Loop: A high-performance asynchronous loop that handles all internal messaging. - Thread Management: Separating slow cognitive tasks from fast reflex tasks. - Base Classes: Standardized interfaces for all modules. - Memory Safety: Managing buffers and preventing leaks in long-running missions.

    3. 🧠 Layer: Brain (The Intelligence)

    Directory: /smartbees/brain, /smartbees/ai Role: High-Level Decision Making.

    The Brain consumes processed environment data and outputs strategic directives. - Quantum Logic: Handles probabilistic states (superposition) when sensor data is conflicting. - LLM Integration: Uses "Deep Thought" loops (during Sleep cycle) to analyze complex mission logs. - Self-Reflection: Evaluates the success of previous actions to update behavioral weights (Federated Learning). - Optimization: Calculates the most energy-efficient paths across the entire swarm.

    4. 🚀 Layer: Application (The Execution)

    Directory: /smartbees/app Role: Tactical Implementation.

    The App layer translates "Directives" into "Actions". - Autopilot: Real-time PID control and trajectory following. - Mission Control: Sequence management (Takeoff -> Explore -> Dock -> Charge). - Navigation: Pathfinding through 3D meshes generated by the vision system. - Behavioral Logic: Swarm formations and "LineCharge" docking maneuvers.

    5. 📡 Layer: Sensors (The Perception)

    Directory: /smartbees/sensors Role: World Awareness.

    The Sensors layer builds a digital twin of the environment. - Data Fusion: Combining LiDAR, IMU, and E-Nose data into a unified state. - State Estimation: Calculating the drone's position and velocity with high precision. - Filtering: Removing noise from environmental readings (AHRS, Kalman filters). - Object Recognition: Edge-AI processing of visual data for obstacle avoidance.

    6. 📶 Layer: Communication (The Social)

    Directory: /smartbees/comm, /smartbees/comms Role: Network Synchronization.

    The final layer connects the individual node to the collective. - Swarm Sync: Sharing state vectors with nearby nodes to maintain formation. - Operator Uplink: Streaming telemetry and receiving manual overrides. - Mesh Security: Multi-layered encryption (Ternary Ratchet) for all mesh traffic. - Redundancy: Seamlessly switching between LoRa, LTE, and Satellite links.

    🔄 The Feedback Loop

    The flow is not just one-way. While the logic flows from Config -> Comm, the Sensors constantly feed data back to the Brain, which adjusts the App behavior in real-time, creating a closed-loop organic system.
